## Optional downloads, not included

Chisa and Wuthering Waves belong to KURO GAMES. `assets/chisa-sources.json` lists the render, wallpaper and gallery sources, including a publication by the official Wuthering Waves account. Other source pages are third-party hosts; their artwork is not represented as freely redistributable or MIT-licensed.

The optional fetcher downloads those resources for local customization. It validates HTTPS, file signatures, size and SHA-256, and stores them under ignored asset directories. The dimmed wallpaper is composed locally and is also ignored. Source archives exclude these downloads.

No full dconf dumps, session logs, private backups, local configuration, embedded third-party wallpapers or screenshots of personal desktop sessions are distributed. The README screenshot uses only the original demo SVG assets and installed app icons.
