# Changelog

## 0.1.0 — initial source preparation

- Extracted modular GNOME 51 desktop from the original local Anime Glass project.
- Added portable installation path discovery and original SVG demo assets.
- Added MIT code license, Orbitron/OFL notices and optional Chisa asset manifest/fetcher.
- Made desktop integrations opt-in and preserved existing local settings/fonts.
- Added portable CI, staged-content publication auditing and source packaging.
- Kept calendar/MPRIS/native-rendering tests and scoped rollback.
- Added native GTK/libadwaita customization for images, colors, glass, motion, clock, greetings and installed application selection.
- Added atomic preferences persistence with pre-edit backup, external-edit merge and invalid-file preservation.
- Enabled modeless, resizable preferences with native titlebar double-click maximize/restore and a maximize button.
- Organized Markdown documentation under docs/; retained only README.md at the repository root.
- Expanded ignore rules for runtime state, downloaded/local artwork, caches, virtual environments, editor files and generated archives.
- Added the official repository URL and install commands; retained the repository owner’s existing MIT attribution.
- Verified the real installer/rollback in an isolated user session and accepted an explicitly reviewed CDN image hash variant.
